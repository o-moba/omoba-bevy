# Current-code Bevy 0.19 migration

The owner requested the latest stable Bevy after consolidating all current gameplay changes. Verified upstream stable release: Bevy 0.19.1, minimum Rust 1.95.0. The historical September migration was isolated and had not reached main; this migration ports the current 0.42.0 game and SDK 0.8 asset/account features rather than restoring that obsolete snapshot.

Target release: game 0.43.0, SDK 0.9.0. Gameplay/network contract stays protocol 10 / standard-kits-5 / compact geometry v2; the engine migration itself adds no wire change.

Changes cover Bevy world-serialization scene types, typed font handles and pixel sizes, material mutation guards, input phases and computed UI stacking. Existing glTF `#Scene0` labels stay intact; UI render order continues to decide overlapping touch targets. Audio remains explicitly enabled in Android's feature set. No signing credentials or production services are changed.

The owner explicitly approved Rust 1.95 pins in the three existing GitHub workflows. Their jobs and publication behavior are unchanged. Verification is recorded in `.agent/tasks/BEVY-019-CURRENT/`; physical phone acceptance remains separate. Desktop visual scope: English, 852×393 logical phone HUD, affected rendering/interaction only.

Sources: https://docs.rs/crate/bevy/0.19.1 and https://bevy.org/learn/migration-guides/0-18-to-0-19/ .

Local verification passed: make check, 1595 Rust tests (39 explicitly ignored), 171 Python tooling tests and 45 mocked iOS packaging tests. SDK verification passed 50 HTTP/account/asset tests and default-feature Clippy including Bevy examples. Remaining native renderer and remote mobile checks are tracked in task evidence; no device or deployment claim is implied.
