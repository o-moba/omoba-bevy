# Bevy 0.19 migration

## Rationale

Bevy 0.19 improves renderer batching and animated mesh bounds, relevant to the
prop-rich arena and imported avatars. Native editable text is a potential later
replacement for custom chat/profile editing. FPS improvements require measurement
on representative hardware; upstream large-scene benchmarks are not game results.

Target the patched 0.19.1 release with Rust 1.95.0. Update the SDK and game
together to avoid incompatible Bevy resource and asset handle types. Preserve
the existing render quality, mobile layouts and network protocol.

## Compatibility changes

- Rename legacy GLB scene roots, assets, instances and spawner imports to the
  world-serialization API. Existing GLB scene labels remain unchanged.
- Preserve pixel-based HUD scaling through typed font sizes; use typed font
  sources for packaged Latin/Cyrillic/CJK fonts and migrate text constructors.
- Use the new HDR module path and shadow-map field name.
- Pin the Rust toolchain per checkout; keep signing and deployment unchanged.

Validation evidence is recorded in `.agent/tasks/BEVY-019-2026-09-17/`.
Physical iPhone frame-time, thermals, keyboard and touch checks remain a release
gate. A desktop mobile-layout capture is not device acceptance.

## Verification

- Game tests: 628 passed (378 client, 58 shared, 8 Passport, 184 server).
  Fifteen PostgreSQL integration tests remain ignored without an isolated database.
- SDK 0.4: ten platform-independent tests passed; default-feature examples compile.
- Locked native client/server build and iOS arm64 client compile check passed.
- Native renderer captures passed for mobile-layout magic, desktop melee, sprite
  combat and moving forest butterflies; screenshots inspected. No runtime render
  errors were reported in these bounded scenarios.
- Cargo resolves a single Bevy 0.19.1 and the published exact SDK Git revision.
- Migration is saved on `chore/bevy-0.19`; main, the running practice server and
  existing signed iPhone/TestFlight artifacts are preserved pending device QA.

The iOS check validates compilation, not linking/signing or performance on a
physical phone. No new TestFlight upload was performed.
