# Beta 0.40.1: retained-seat account polling

A real authenticated remote smoke test of 0.40.0 reached gameplay with Adventurer, all three tower tiers, dash and haste. Reconnect then failed: `poll_career` treated the retained human at an internal bot-controller address as an unauthenticated network endpoint. It marked the actor unjoined, preventing reclaim and allowing empty-roster abandonment. Earlier tests exercised roster maintenance and Join but omitted career polling.

The patch exempts only registered retained seats matching the internal address, player ID and session. Existing signed Join, allocated profile/session checks and normal endpoint invalidation remain in force. Regression coverage includes both transport timeout and Leave, polling beyond empty-roster grace, reclaiming the same hero, and negative cases for unregistered or changed identities. The positive test failed before the fix.

Version 0.40.1 keeps protocol 9 / standard-kits-4 and is compatible with iOS 0.40.0 (19); no client rebuild is required for this server-only behavior change. No database migration, credential change or new production dependency is needed.

Deployment and verification results will be appended after the candidate passes its checks and the remote test is repeated. Raw task evidence: `.agent/tasks/RETAINED-SEAT-AUTH-20261004/` and `.agent/tasks/BETA-040-20261004/` in the primary checkout.
