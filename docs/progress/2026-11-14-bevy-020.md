# Bevy 0.20 upgrade

Branch: `feat/bevy-0.20`, based on the fetched `origin/dev` revision `fe922f02`.
The workspace source version advances from 0.45.0 to 0.46.0.

## Scope

Upgrade the desktop/mobile client, browser client, wasm shared clock and pinned
Ekza Bevy SDK to Bevy 0.20. Rust advances from 1.95.0 to the Bevy 0.20 MSRV,
1.97.1. The server remains renderer-free; no network protocol, gameplay, dev
deployment or release-publication change is intended.

The SDK change is published at immutable revision
`b67b33fde4ceba3084a771905d9660ca6659dfb0` on `feat/bevy-0.20` of
`ekza-space/ekza-bevy-sdk`. Its engine-free suite passes 28 tests and formatting.
The game lock resolves every Bevy crate to 0.20.1 and the SDK to that revision.
`cargo tree -p client -i bevy` reports one Bevy version. Bevy 0.20.1 still uses
cpal 0.17.3 through rodio 0.22.2, so the existing Linux recovery patch stays.

## Migration

The official 0.19-to-0.20 guide was applied. The two mesh-bound call sites move
from `MeshAabb::compute_aabb` to `MeshAabb::get_aabb`. No custom naga_oil WGSL
shaders, old generic pointer events, lifecycle observer generics or BSN templates
are present in this workspace. CI, Linux build documentation and release build
images use Rust 1.97.1 consistently.

## Verification

Local heavy Rust compilation is deferred because the system volume had less than
20 GB free when the task started. Fresh GitHub CI on the pull request into `dev`
is the authoritative full workspace/client/server gate. Final command results and
any follow-up fixes are recorded here and in
`.agent/tasks/BEVY-020-20261114/`.
