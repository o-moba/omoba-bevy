# Cross-app publication and persistent Ekza account

Implemented SDK credential persistence, asynchronous restoration, revocation-aware
refresh and a visible local logout. SDK pinned to Git `42c39e4` (0.7.0).

A real local Studio publication of Robert was processed and approved for Omoba,
Space and Mirror. The desktop client connected by code, listed the exact model in
My Ekza library, downloaded verified GLB bytes through the SDK and rendered it in
an actual match on the isolated port 4028 server. Restart restored the account
without pairing; logout removed the private credential file. Screenshots and
fresh check results are in `.agent/tasks/EKZA-CROSS-APP-20260921/`.

This rehearsal does not deploy production services, modify the running phone
practice server, or prove mobile rendering/AR tracking. The existing career
account and wallet ownership systems retain their separate permissions.
