# 2026-09-17 — Orbital Supporter VFX

Implemented the requested hero-aura direction in the actual game renderer, inspired
by luminous hero effects and electron-like orbital movement. Server-authorized live
local/remote actors and the isolated native preview share the same spawn/animation
path. Three inclined orbits carry bright cores, translucent camera-facing glow sprites and tapered
analytical trails. Four sparse rising glints and a restrained ground ring complete
the effect. Solar, Lunar and Verdant preserve their existing server-selected colors.

There are 35 rendered entities per active aura, shared meshes/materials, no per-frame
spawning, no dynamic lights, and no requirement for a bloom pass. The 2D projection
puts near-side particles in front of the sprite and far-side particles behind it.
Visibility, death, style changes, owner removal and gameplay stats retain their
existing lifecycle and authorization rules.

Validation evidence: `.agent/tasks/AURA-VFX-2026-09-17/`. Physical iPhone performance
is not established by desktop rendering. This is a source update; the already uploaded
TestFlight build 0.20.0 (4) contains the earlier basic aura, not these new effects.

The linked-worktree attempt hit pre-existing root-owned Git administration directories.
Implementation therefore used a temporary shared-object clone on a dedicated branch,
with the current dirty source baseline overlaid and recorded before changes.
