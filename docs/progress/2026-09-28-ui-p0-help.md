# 2026-09-28 — Verdant Crown controls guide (rebrand P0-C)

Proof-loop task `UI-P0-HELP` (program HQ `omoba-ui/rebrand/`, spec
`omoba-ui/handoff/screens/hud-help.md` + `VARIANTS.md` `in-match-first`,
`home-help`). Goal: replace the one-block help text with the illustrated
control cards of the handoff on desktop and phone, in English and
Simplified Chinese, and let Settings → Controls return to Settings (R6.5).
No version bump here (the coordinator bumps at merge).

## Changes

- **Desktop guide:** framed panel 1088×672 over `color.scrim`: centred
  eyebrow and `type.title`, six cards (Move, Attack, Target, Abilities, Shop,
  Objective) 336×192 with an icon disc, gold heading, body and a legend row
  (muted badges for mouse inputs, keycaps for keys from the bindings), the
  Read the field / Camera strip, a 360-wide primary large "Enter the arena"
  and the reopen hint. Geometry matches the redline to the pixel at
  1280×720 (unit test). A desktop match window smaller than the reference
  scales the panel down so it stays whole.
- **Phone guide:** plain panel in `MobileControls.safe` (+16 sides, 12 top
  and bottom), title row with the 240-wide dismiss, ten cards 96 high in two
  columns in the touch scroll list plus the closing line, and a gold scroll
  thumb.
- **i18n (R2.1):** `help.body` / `help.phone.body` / `help.dismiss` split into
  `help.card.<id>.title|body`, `help.phone.card.<id>.title|body`,
  `help.phone.title`, `help.phone.footer`, `help.reopen`,
  `help.dismiss.button`, `help.input.left_click|right_click` (English is the
  existing copy line by line; new English only for the card titles and
  mouse chips proposed by the handoff), plus `pause.settings.controls`. No
  new zh-Hans characters, so the display subset still covers them.
- **Modal + controller:** the shown guide is `ModalId::Help` (layer 110), so
  a controller's focus starts on the dismiss button and the HUD/Home under it
  waits; Esc, gamepad East, F1 and the button close it as before.
- **R6.5:** Settings has a Controls entry (`PauseMenuSettingsControlsButton`);
  closing the guide opened there reopens Settings
  (`pause_menu::SettingsHelpReturn`); the Game menu's Controls guide still
  returns to the game.
- **Kit:** `surfaces::info_card` (help card) and `surfaces::keycap`.
- **Phone layout pass:** `mobile_ui` no longer resizes or refonts the help
  panel (the guide places itself); legacy `PHONE_HELP_W` and
  `PhoneText::Help` removed.
- **QA:** `OMOBA_HELP_QA_SHOTS=<dir>` (`qa/help_qa.rs`) captures the
  controller focus on the dismiss button, the scrolled phone list, the close
  and the Settings round trip, with checks in `result.json`.

## Checks

`make check` (fmt, workspace clippy `-D warnings`, clippy
`--no-default-features`, workspace tests, script tests) with the shared
cargo cache; `make ui-audit` runs `match`, `shell`, `flow` in English and
zh-Hans on both profiles against the 0.27.0 baseline; the help harness on
desktop and phone in both languages. Evidence in
`.agent/tasks/UI-P0-HELP/`.

## Risks / follow-ups

- The desktop match keeps `UiScale` 1.0 (R2.3a), so on a large window the
  guide keeps its 1280×720 size; it scales with the match once F8.1 lands.
- `home-help-closed`: controller focus after closing the guide goes to the
  first button of the screen, not back to the Help button (the kit focus
  restarts on a changed surface, pinned by its tests); a focus memory is a
  kit change for the Home step.
- The controller legend strip (`gamepad.legend.menu`) sits at the top edge
  while the guide is open with a controller; it overlaps the desktop panel
  frame by a few pixels.
- Settings → Controls is a list button until the Settings tab rail (P1-D).
