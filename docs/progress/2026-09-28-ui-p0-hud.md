# 2026-09-28 — Verdant Crown in-match HUD (rebrand P0-A)

## Goal

Rebuild the match HUD from the Verdant Crown handoff
(`omoba-ui/handoff/screens/hud.md`, `target-hero|minion|neutral|structure.md`,
`skill-description.md`, `VARIANTS.md`) on the 0.27.0 kit, for desktop
(1280×720 redline) and phone (844×390 redline), English and Simplified
Chinese; make world-anchored overlays follow `UiScale` so the desktop match
can scale (rebrand TODO F8.1). Proof loop `.agent/tasks/UI-P0-HUD/`.

## Changes

- **One layout table** (`client/src/hud_layout.rs`): every hud.md region in
  logical UI px (desktop edge-anchored, phone on `MobileControls.safe`, top
  row 12 px from the screen top); owners tag roots with `HudRegion` and
  `place_hud_regions` places them. Tests pin the redline coordinates.
- **Desktop**: minimap frame 176 (2 px `gold.500` + 1 px `gold.700`, glass);
  status plate (portrait 56 + XP ring + level disc, HP 200 × 14 with
  low-HP colours, mana 156 + `{mana}/{max}`, gold row = shop button with the
  `P` keycap, XP tooltip); buff chips (+ the offline practice badge on top,
  R5.6); target plate for hero / minion / neutral / structure; brush badge;
  score strip button (`{green} : {blue}`, `K / D / A`); chat / reactions /
  menu icon buttons with tooltips; social status chip; action feedback toast;
  upgrade chip (`+ UPGRADE` + `U`, spends like `U`); ability bar on kit
  ability buttons (key, cost pill, cooldown sweep + seconds, 3 pips, `+`
  badge, `Lv N` veil, ready flash; no names under the slots); the ability
  tooltip (`skill-description.md`); equipment plate (6 slots + 2 quick-buy
  offers with price and reason tooltips).
- **Phone**: minimap 120, status plate 200 × 48, quick-buy row; target plate
  220 × 44 between minimap and score strip; score strip 150 × 44; 44 px icon
  buttons; the combat group on two arcs around ATK 96 (abilities 64 on R 104,
  DASH / HASTE / CANCEL / RANK / MIN / TWR 48 on R 168), joystick base r 52
  and knob r 24, each ability's rank as the segmented rank ring on its rim
  (3 arcs, learned gold, DECISIONS R10, kept from 0.26), `+` badges and gold
  rims in rank mode, the hold card at the top centre, the aim hint in the
  feedback slot, the practice toast.
- **Target plate**: new keys `edge.target.minion_melee|minion_caster|tower|
  base|boss`; bosses get the crown disc, a strong rim and the BOSS badge,
  towers their lane badge, the base a strong rim. **R7.1**: protected enemy
  structures are selectable for inspection (lock + 55 % bar), never
  attacked: a right-click says `combat.cast.protected`.
- **Skill card** (`combat/skill_card.rs`): one content model for the desktop
  tooltip and the phone hold card; keys `combat.skill.mana|cooldown|
  hint_touch`; `touch.skill.card` and `touch.ability.no_mana` retired.
- **F8.1**: boss nameplates, floating combat numbers, chat bubbles, the
  reaction wheel centre, the lock frame and the aim preview divide viewport
  points by `UiScale` (`hud_layout::world_to_ui`); minimap clicks convert
  back. The desktop match now uses the R2.3a scale above 1280×720.
- **Kit**: `KitSkin::Plate` / `plate_button`, `live_portrait` /
  `PortraitView`, `ability_face` / `AbilityFace`, `AbilityView::unlock_level`,
  `bar_parts` / `BarKindTag`, `TooltipText`, ability art following the view;
  the gallery HUD page shows the skill card.
- **QA**: beta-UI harness checks the new minimap, desktop/phone required
  controls and the two-arc geometry; target fixtures carry kind data; the
  opt-in upgrade fixture also pins a cooldown and low mana.
