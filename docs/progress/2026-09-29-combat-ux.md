## Where to try

Use this worktree's `make practice` or Offline Practice. Open the game menu's
Practice tools for "Spawn target dummy" and "Spawn moving target (circle)".
Touch: tap the map/world to walk; drag to pan; moving the stick cancels the route
and returns the camera to the hero. Desktop: right click orders movement; left
click/drag on the minimap pans. Space returns desktop camera focus to the hero.
The new UI is not installed on an iPad/iPhone by changing repository files.
