# Hero code map

Start with the class row. The class link opens its role, base stats, growth, and
default Q/W/E/R order. The runtime links point to the branches that apply those
abilities. The tests column gives focused examples to start with.

## Shared entry points

- **Class IDs and roles** come from [`HeroClass`](../shared/src/lib.rs#L179) and the [hero catalog](../shared/assets/catalog/heroes.json). The class order in this guide follows the catalog.
- **Online and offline casts** pass through the [server packet dispatch](../server/src/runtime/dispatch.rs#L434) and [offline practice](../common/src/offline.rs#L186) into [shared combat commands](../common/src/command.rs#L78). The five legacy kits use [`handle_cast_request`](../common/src/sim/cast.rs#L51). Equipped kits use [`skills::cast`](../common/src/skills/mod.rs#L919), which resolves the skill equipped in the requested slot.
- **Equipped kits** use the [frozen core presets](../shared/src/loadout.rs#L325) and [skill catalog](../shared/assets/catalog/skills.json). The [hero catalog loader](../shared/src/catalog.rs#L294) checks each default kit against its preset. For a Workshop recipe, trace the equipped skill's [`SkillEffect`](../shared/src/loadout.rs#L599) or [`Technique`](../shared/src/loadout.rs#L554) to the handler. Follow [the effect tick](../common/src/skills/mod.rs#L1247) and [advanced ticking](../common/src/skills/advanced.rs#L1882) for effects that arm, move, or expire after a cast.
- **Basic attacks** use the [class attack definitions](../shared/src/lib.rs#L136), [attack admission](../common/src/basic_attack.rs), and [shared hit hooks](../common/src/skills/mod.rs#L744).
