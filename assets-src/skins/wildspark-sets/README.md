# Wildspark skin sets

Two original alternative Wildspark sets, **Candy Neon** and **Scrap Punk**. Each
is one `handheld-glb-v1` weapon GLB carrying both the repeater and the launcher,
following the [set convention](../../../docs/wildspark-skin-sets.md). They are
creator-loop upload candidates, not packaged game assets: nothing under
`client/assets` references them.

Geometry, materials and the two Scrap Punk tiling textures are generated by
`scripts/build_wildspark_skin.py`; no downloaded geometry or textures. The GLBs
and rendered PNGs in this directory are **CC-BY-4.0**. Credit them as each
`manifest.json` `attribution` line states, which is also embedded as the GLB's
`asset.copyright`. The generator script and manifest metadata keep the
repository's MPL-2.0. See the [repository license map](../../../LICENSING.md).

Regenerate and check from the repository root:

```sh
python3 scripts/build_wildspark_skin.py --theme all
python3 scripts/build_wildspark_skin.py --verify
```

Each `<theme>/` holds `<theme>-wildspark-set.glb`, `cover.png` (640 × 480),
`repeater.png` and `launcher.png` (512 × 512) and `manifest.json`: hashes,
counts, bounds, licence, attribution, grip and the Studio, registry, game,
budget and convention gate results.
