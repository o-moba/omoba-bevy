# Open Moba repository instructions

## Hero classes and abilities

For work on hero kits, combat behavior, role balance, or hero presentation, start with the [hero code map](docs/hero-code-map.md) and follow the [class navigator skill](.agents/skills/omoba-class-navigator/SKILL.md). The map links each class to its catalog data, combat handlers, and focused regression tests.

Update the affected row when you add or rename a class, change kit behavior, or move its implementation or tests.
