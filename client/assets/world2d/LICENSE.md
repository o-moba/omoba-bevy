# Omoba full-2D world art license and provenance

The bitmap assets in this directory were produced specifically for
`TASK-FULL-2D-WORLD` on 2026-07-27. The source images were generated only via
the Higgsfield MCP using model `recraft_v4_1` (Recraft V4.1), then mechanically
cropped, resized, chroma-keyed, tinted for team accents, and assembled into
runtime atlases by the checked-in task build script. No third-party artwork or
existing game asset was used as a source or generation reference.

The project dedicates these original derived assets to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/):

- `terrain-atlas.png`
- `props-atlas.png`

Exact prompts, Higgsfield job IDs, source URLs, hashes, preflight costs, and the
deterministic cleanup script are retained under
`.agent/tasks/TASK-FULL-2D-WORLD/raw/higgsfield/`. The manifest and build
metadata remain covered by the repository's normal license.
