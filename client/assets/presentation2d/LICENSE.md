# 2D presentation asset license and provenance

The bitmap assets in this directory were produced specifically for
`TASK-2D-RELEASE-VERTICAL-SLICE` on 2026-07-27 with OpenAI image generation and
task-specific chroma-key cleanup, resizing, atlas assembly, and validation.
The five previously produced Omoba sprite heroes were used only as internal
identity/style references for the portrait strip. No third-party artwork was
incorporated.

The project dedicates these original assets to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0):

- `actors.png`
- `effects.png`
- `arena.png`
- `ui-frame.png`
- `portraits.png`

The manifest, metadata, and runtime code are covered by the repository's normal
license. Exact generation prompts and source outputs are retained under
`.agent/tasks/TASK-2D-RELEASE-VERTICAL-SLICE/raw/designer-b/`.
