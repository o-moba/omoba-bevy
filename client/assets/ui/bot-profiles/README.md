# Bot profile portraits

Open Moba generated 30 original portraits on 2026-11-24. The first ten use the built-in OpenAI ImageGen tool and the next twenty use GPT Image 2.6 through Higgsfield. Each portrait had its own text prompt and used no reference images. The shipped files were downscaled to 192 × 192 RGB PNG for roster UI. Open Moba contributors make the images available under [CC BY 4.0](../../../../LICENSES/CC-BY-4.0.txt) to the extent they hold rights in the output. Credit Open Moba contributors and preserve this provenance.

The roster uses stable persona IDs for the filenames. See the [persona catalog](../../../../shared/src/bot_personas.rs).
