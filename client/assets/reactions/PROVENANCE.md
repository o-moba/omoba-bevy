## Accepted generation prompt

Create one square transparent PNG game UI sprite atlas with exactly four original
cartoon sticker icons in a clean 2x2 grid, each centered in its quadrant with ample
transparent padding: top-left gold-and-teal armored hand thumbs up, top-right same
hand thumbs down, bottom-left coral heart, bottom-right joyful laughing mint slime
face. Consistent bold teal outlines and ivory sticker edging, simple legible 64px
silhouettes, polished soft cel shading. No existing game characters, no text,
labels, logos, frame or grid. Genuine alpha transparency. Equal 2x2 cells, no
elements crossing midpoint divisions, square 1024x1024 preferred.

The returned dimensions differ from the preferred size; the renderer reads the
actual atlas dimensions instead of assuming a 1024-pixel image.
