# Sprite asset license and provenance

The original five locomotion sprite sheets in this directory were produced specifically
for `TASK-2D-SPRITE-PROTOTYPE` on 2026-07-27 using OpenAI image generation and
task-specific cleanup/assembly. The five attack/cast/hit/death sheets under
`actions/` were produced for `TASK-2D-RELEASE-VERTICAL-SLICE` using the existing
characters as identity references, OpenAI image generation, chroma-key cleanup,
and task-specific grid assembly. They do not incorporate third-party artwork.

The project dedicates these five original sheets to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/):

## TASK-2D-CHARACTER-PACK-02 additions

The following five characters were produced as original work for
`TASK-2D-CHARACTER-PACK-02` on 2026-07-27. Artistic bitmap sources were generated
exclusively through Higgsfield MCP: one approved static master and selection
portrait plus six reference-guided Seedance clips per character. Runtime sheets
were assembled from intentionally selected source frames using deterministic,
non-generative extraction, white-matte/despill, registration, scaling, and
packing. No third-party, stock, downloaded, traced, or other-game art was used.

The project dedicates these additions to the public domain under CC0 1.0
Universal. Exact prompts, provider model/job/media identifiers, returned cost
records, source clips, frame mappings, cleanup commands, hashes, authorship, and
QA live under
