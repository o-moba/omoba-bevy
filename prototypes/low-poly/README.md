# OMOBA · Low-poly прототип

Одна дорожка, мост через реку, две базы и один персонаж в двух командных цветах. Для силуэта использованы асимметричный капюшон, плащ-колокол и тонкие тёмные конечности. В Blender обе команды используют одну геометрию, а цвет задают два слота материала.

Геометрия арены, персонажа и башен создана процедурно в Blender для этого прототипа. Референсы задали направление силуэтов и палитры. [Скрипт Blender](build_scene.py) воспроизводит модели и игровые экспорты.

## Сыграть в ARAM 3×3

- [Одиночный матч](aram/play.html) открывается прямо в браузере. Выберите стрелка, танка или саппорта. Остальными героями управляют боты.
- Управление — WASD, стрелки или нажатие по дорожке. Нажмите на врага, чтобы выбрать цель, или удерживайте пробел для атаки ближайшего врага. Q запускает способность. Атака и способность также доступны кнопками на экране.
- Башня каждой команды стоит посередине между рекой и нексусом. Миньоны идут волнами. Чтобы повредить нексус, сначала разрушьте башню. Побеждает команда, разрушившая вражеский нексус.
- В общей комнате до трёх участников занимают роли синей команды. Боты заполняют свободные роли и играют за коралловую команду.

Чтобы открыть общую комнату в локальной сети, запустите из корня репозитория с Node.js 22 или новее:

```sh
node prototypes/low-poly/aram/server.mjs --host 0.0.0.0
```

Откройте один и тот же адрес из вывода сервера на устройствах в этой сети. Для проверки с одного компьютера запустите команду без `--host` и откройте `http://127.0.0.1:8080/` в разных вкладках.

[Редактируемая ARAM-арена](low-poly.blend) открывается на сцене `04 ARAM`. [Рендер](aram-arena.png) показывает расстановку 3×3, а [игровой GLB](aram-arena.glb) содержит статические декорации и отдельные модели башен и нексусов. Сцена `05 Towers` и [крупный план](tower-study.png) показывают башню в обеих командных палитрах.

[Предыдущая версия арены с каменными воротами](aram-stone-gates.blend) открывается как отдельная сцена Blender.

## Посмотреть

- [Интерактивная арена](viewer/preview.html) открывается локально в браузере с WebGL 2. Кнопки выбирают команду. WASD, стрелки и нажатие по карте двигают выбранного персонажа. В этом режиме используется фиксированная поза с поворотом по направлению движения.
- [Исходник Blender](low-poly.blend) также содержит сцены `01 Arena`, `02 Team colors` и `03 VRM source • T-pose`. В третьей доступны исходные меш и скелет.
- [Игровой ракурс](arena.png) и [сравнение цветов](team-colors.png) отрендерены в Blender.
- [character.vrm](character.vrm) содержит VRM 1.0, T-позу и скин с 21 костью. Модель смотрит по +Z и содержит 1 504 треугольника. Для игрового корня OMOBA, где направление вперёд соответствует −Z, понадобится разворот дочерней модели на 180°.
- [arena.glb](arena.glb) содержит геометрию арены. [character-preview.glb](character-preview.glb) содержит позу персонажа для браузера.

## Пересобрать

Из корня репозитория с Blender 5.0 в PATH:

```sh
blender --background --factory-startup --python-exit-code 1 --python prototypes/low-poly/build_scene.py
python3 prototypes/low-poly/viewer/build_preview.py
python3 prototypes/low-poly/viewer/build_preview.py --aram
node --test prototypes/low-poly/aram/match.test.mjs
```

Чтобы перекрасить персонажа в исходнике T-позы, поменяйте `Team Cloth` и `Team Trim`. В сценах сравнения синий и коралловый варианты заданы на уровне объектов. Браузерный просмотр применяет те же два слота к каждому экземпляру.
